# Dataset

Obtain `Delhi_AnandVihar_2025_Aug2026_11pollutants_combined_unimputed.csv` from the team and place it in this folder. The source CSV is kept local and excluded from Git. It contains hourly measurements for 11 pollutants from January 2025 through August 2026.

Train/validate on 2025. Test on 2026. Missing readings are left blank in the source file. Fit any filling/scaling on training data only. Document the original collection source before publication.
