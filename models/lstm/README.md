# Model 5: LSTM

Contributor: Rishuta Sheel (@rishuta).

Run from the repository root: `python models/lstm/train.py`

Place the two source CSVs in `data/raw/` first. Override with `--data-dir PATH`. See `docs/recurrent_methodology.md` for the full experiment.

The results folder contains the trained checkpoints, epoch-selection histories, predictions and error tables for daily, weekly and monthly comparisons. AQI classification is pending.
